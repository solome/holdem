# Holdem · 掬一捧的德州好牌图鉴

[在线打开 Holdem](https://solome.js.org/holdem/)：德州扑克成就图鉴、起手牌矩阵、牌局复盘、现金桌学习手册及牌力计算。支持添加到手机主屏幕，首次联网加载后可离线使用。

[网站说明](apps/web/README.md)介绍功能和安装方法。[共享玩家池](shared/players.json)维护牌友身份和头像资料。

从仓库根目录运行 `npm --prefix apps/web ci` 安装网站依赖，再运行 `npm --prefix apps/web run dev` 本地预览。推送 `main` 后由 GitHub Actions 构建并发布网站。
