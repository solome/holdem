# 德州决策引擎验证 · 2026-09-29

机器数据：[holdem-decision-verification.json](holdem-decision-verification.json)。版本 5，所有模拟玩家已接入同一通用引擎。

## 策略回归

同一公开信息集、7 个模拟风格、每风格 16 个种子，共每场景 112 次选择；当前每次使用生产预算 128 组联合样本。旧版使用同样的场景与动作种子进行比较。频率只代表这些固定场景，不是实战总体频率。

| 场景 | 第 4 版下注 | 第 5 版下注 |
| --- | ---: | ---: |
| AK，翻前主动，单挑 Q72 彩虹面 | 9.82% | 85.71% |
| AK，翻前主动，单挑 884 彩虹面 | 9.82% | 85.71% |
| AK，翻前主动，单挑 987 两同花面 | 9.82% | 21.43% |
| AK，翻前主动，四人 Q72 彩虹面 | 9.82% | 6.25% |
| JJ，单挑 T62／832 彩虹低张面 | 69.64% | 93.75% |

冷跟开池或跟了别人 3-bet 的玩家不被计为翻前主动者，其主动下注不会误标为 c-bet。AK 在转牌改善听牌时继续下注 48.21%，空白转牌 1.79%；本组错过河牌场景全部过牌。它们检验对公开行动与牌面变化的敏感性，不要求所有 AK 都下注，也不据输赢判定策略。

AA、KK、QQ、AKo、AKs 各 20 个种子共 100 手首次入池回归，生产预算下均选择跟注或加注。最初 24 样本的 AKo／种子 12 出现一次误弃：加注估计 −0.0875 BB；同信息集 128 样本估计 +0.9012 BB，512 样本 +0.9823 BB，均选择加注到 3 BB。测试保留原断言并改用生产预算，未加牌名强制行动规则；低预算不适合细微策略判断。

## 随机整桌检查

192 手固定种子、每次决策 24 样本，用于检查动作、合法终止和范围变化，不用来标定生产频率。与旧版配对发同样的牌：翻前结束 7.29% → 18.23%，看到翻牌 92.71% → 81.77%，三人以上看到翻牌 65.10% → 37.50%。新引擎未为了凑娱乐比例强留玩家。小样本、低抽样预算和模型更新都会影响这些比例。

新版样本包含翻后下注、加注、再加注和过牌后加注；这批有限样本没有发生河牌加注，不能据此声称每街在该样本都出现加注。独立收益与状态机测试覆盖河牌的合法价值加注。

## 性能与集成

独立新 Node 进程、生产 128 样本：冷首次决策约 16.93 ms；32 次决策平均 6.47 ms、P95 14.80 ms；8 手完整模拟平均 81.24 ms、P95 112.90 ms。测量受机器、进程预热和牌局长度影响，不是浏览器延迟保证。

`npm run check`：187 项测试全部通过，随后成功构建自包含 `index.html`。检查覆盖联合无撞牌抽样、沉没成本、多人跟注和平局、未匹配退款、条件跟注权益、公开信息隔离、负估计收益动作拒绝、固定座位与本地恢复。浏览器已验证四街切换、价值下注、弃牌灰态、行动浮窗、退款与仅轮转位置；未出现页面错误日志。

这些验证说明实现和若干策略行为符合预期；尚无对战基线证明长期盈利。模型与缺失功能见[引擎文档](holdem-decision-engine.md)。
