# Holdem UI 尺度

保留奶油白、墨绿与四色扑克牌，以及首页的衬线字体。功能页以可读性、一致的组件尺度和清晰的选择状态为主。

## 参考依据

2026-09-28 查阅的官方规范：

- [Atlassian Typography](https://atlassian.design/foundations/typography)：区分标题、正文与辅助文字，结合字号和行高建立层级。
- [Atlassian Spacing](https://atlassian.design/foundations/spacing)：用统一刻度代替逐处指定不同间距。
- [Atlassian Radius](https://atlassian.design/foundations/radius)：按控件、内容容器、浮层的角色分配圆角。
- [Apple Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)：图标视觉尺寸与可点击区域分开考虑，保持控件尺寸一致。

以下是本项目对这些原则的取舍，并非照搬某一平台的全部规范。

## 本站规则

| 项目 | 取值 |
| --- | --- |
| 间距 | 4、8、12、16、20、24、32、40px |
| 圆角 | 扑克牌 6px；控件 8px；面板 12px；弹窗 16px |
| 界面文字 | 正文／按钮 14px；辅助文字 12px；弹窗标题 24px |
| 行高 | 正文约 1.5；标题约 1.3 |
| 图标按钮 | 20px SVG 图标；桌面 40px、触控 44px 点击区域 |
| 面板内边距 | 桌面 24px，手机 16px |
| 功能字体 | 沿用本地系统无衬线字体；首页品牌展示与扑克牌保留衬线字体 |

学习文章正文与表格采用 15px；正文色为 `#29382e`，说明文字为 `#495648`，次要信息为 `#53614f`。页面直接以标题和内容介绍开头，省去装饰眉题、重复标签与口号。

导航下拉与语言切换共用菜单颜色与圆角。面板内边距 4px，选项之间不额外留空。桌面选项至少 32px 高；触屏下二级导航至少 44px，语言选项至少 36px。

现金桌学习页的小节标题直接使用知识点名称，如「决策框架」「期望和期望值」。解释放在正文，牌局里的具体问题放在决策处。

教学文字可以借牌局里的节奏、来路和进退增加余味，意象应当帮助解释判断；不另设装饰眉题、空泛标签和口号。

## 教学正文中的手牌

教学正文提到具体起手牌时，把牌名与两张小牌放在一起。比较双方牌力时，每一手都要配图，即使该手牌已在段首出现。例如「同样的 KQ 可能撞上 AK 或 AQ」要让读者在这句话里看到三手牌。重复指向同一手牌时保持同一花色；同一局面的不同玩家不能占用同一张牌。

保留 KQo、76s 之类的记号，方便回到矩阵查找。s 用同花示例，o 用非同花示例。只写 AK、JJ 而没有花色信息时，可用两张点数牌；如果花色影响这次比较，就明确给出一组合法示例。实际牌局或固定权益计算须使用原有花色。牌名、点数和花色符号应可读，窄屏时两张牌成组换行。

现金桌正文用 `<cash-hand>AK</cash-hand>` 表示未指定花色，`<cash-hand example="Ac Kd">AK</cash-hand>` 指定示意组合，`<cash-hand cards="Kd Qs">KQo</cash-hand>` 记录具体牌例。目录、矩阵格子和操作链接使用紧凑记号；金额、公共牌、补牌点数及 Ax 等泛指范围应按原意展示。

## 手机与折叠屏

按可用视口排版，不绑定设备型号。1024px 以下导航单独成行，移动端用紧凑目录跳转文章章节；380px 以下导航采用两列。文章保持 15px 正文，双列表格随容器换行，宽表格在内部横向滚动并固定行标题。牌例、卡片和图示随宽度收拢。

通过 `viewport-fit=cover` 与四侧 `safe-area-inset-*` 为异形屏留白；固定弹窗和两类菜单遵守同一安全区。菜单根据可视视口定位，短屏可向上打开并滚动，旋转和收折后重新定位。

浏览器上报屏幕分区时，页面在首个连续分区读写，横向分屏避开铰链，纵向分屏在上方独立滚动，弹层使用同一范围。单屏或不提供分区数据的浏览器继续按实际视口排版。网页弹窗使用均匀遮罩，不对背景实时模糊。

验证包括 280–1280px 的窄外屏、常见手机及展开屏视口，以及短高度横屏；另外在菜单展开时改变宽高，核对边界、滚动和键盘焦点。浏览器模拟用于检查布局与交互，设备验收需补真实浏览器与真机测试。

关闭图标使用同一份对称 SVG，按钮清除默认内边距，通过网格居中。不得用字体字符 `×` 或临时位移微调图标位置。牌面不叠加删除叉号；在牌库点击同一张牌切换选中状态。

13×13 起手牌矩阵与扑克牌角标属于密集图形，可使用更小字号；普通说明、日期、按钮不采用这些小字号。圆形开关、状态点、进度环保留其功能所需形状。

## 趣味牌桌

参考 [BBO Rockwell 的实物桌型](https://bbopokertables.com/poker-dining-table)，采用两端饱满的跑道形轮廓，桌面宽高约 2.1:1。墨绿桌沿、细内线和轻阴影形成边缘层次；毡面保持原有绿色，不增加灯带、木纹或写实配件。七席在桌面采用上三、下二、两端各一，手机采用上三下四，并使用独立的紧凑比例，避免把横向桌型挤成尖头竖椭圆。

翻牌前／翻牌／转牌／河牌使用轻量分段控件，字号 12px，桌面至少 32px 高，触屏至少 44px。阶段切换不改变桌面高度；浮窗挂在页面顶层，避免被桌沿裁切。

## 验证重点

桌面与窄屏均检查：关闭图标的几何中心、文字换行、弹窗操作区可达性、五张公共牌是否越界、矩阵与下拉菜单是否溢出。保持既有牌型逻辑、草稿取消语义与撤销行为。
