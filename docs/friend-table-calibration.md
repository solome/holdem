> 本文保留第 1–4 版娱乐策略的历史校准。当前第 5 版已接入[德州决策引擎](holdem-decision-engine.md)，优先比较行动的估计收益；下文旧版频率不是当前结果，10%／90%／60% 不再作为强制配额。

2026-09-29，按用户指定的娱乐局节奏，将默认策略从版本2调整到版本3。此前版本2为翻前结束57.58%、看到翻牌42.42%、三人以上看到翻牌6.32%。

## 目标口径

用户要求翻前结束约10%、看到翻牌80%、三人以上看到翻牌60%。翻前结束与看到翻牌是互补事件，故本次按**约10%翻前结束、约90%看到翻牌（80%为下限）、约60%的全部牌局由三人及以上看到翻牌**实现。

这些是用户指定的娱乐生成频率，并非真实牌友统计、通用朋友局标准或GTO建议；目标约束统计样本，不设置逐局配额。

## 策略变化

- 引入大量1BB平跟及跟着入池（limp／overlimp）。约33.94%的起手组合适合低成本参与，其中QQ+/AK继续主动加注；其余根据手型正常弃牌。
- 保留对子、同花A/K、同花连张／一缺口及部分有可玩性的杂色牌；去掉最边缘的一组同花大缺口牌，避免多人比例过高。
- 已平跟后补2BB，与未投入直接跟3BB分开评估。普通小额跟注更宽松；10BB再加注、贵注、筹码不足仍有独立限制，不能因已经入池就一直跟。
- 下注按真实顺序执行，强制盲注、免费过牌、最小下注、跟注差额、未跟注退款和提前收池继续校验。
- 发牌与座位仍随机；决策由自己的手牌、当时公开牌面与下注信息确定，没有混频随机弃牌、重洗挑牌、偷看未来或事后补玩家人数。翻后规则未改。
- 原有缓存保留同一局的人物、牌面和起始筹码，按策略版本3重新生成行动。起手牌矩阵与两手真实牌谱分析不随这个娱乐频率调整。

## 重现与回归

`npm run analyze:friends -- --hands 10000 --seed 20260929`

`npm run analyze:friends -- --hands 10000 --seed 20261007`

需要纯JSON时直接运行 `node scripts/analyze-friend-table.mjs` 并传同样参数。统计脚本区分平跟、自愿入池和免费看翻牌；BB在未加注底池中免费过牌不算VPIP，因此较低VPIP不代表它没看翻牌。

自动回归同时检查两种子样本的宽容差频率护栏和合法行动、筹码守恒、真实听牌、强牌保护、原AK错误修复、缓存保留及不读取隐藏信息。正常随机生成仍可能出现短局或连续短局。
