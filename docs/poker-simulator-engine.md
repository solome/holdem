# 朋友局模拟引擎

## 分层

- `src/poker-engine.mjs`：下注状态机。负责盲注、行动顺序、当前需匹配的下注额、最小加注增量、待回应队列、筹码校验、未跟注退款和提前结束，不负责判断哪手牌应该打得激进。
- `src/holdem-decision-engine.mjs`：所有玩家共用的德州决策引擎。根据公开对手范围联合抽样，比较合法候选动作的增量预期收益，输出动作、金额、意图、原因、概率与分析依据。
- `src/holdem-ranges.mjs`：公开行动到对手组合权重的模型，以及假想对手对下注的回应概率。
- `src/friend-player-brain.mjs`：每个玩家的薄适配器，维护模拟风格、本人决策次数和独立随机序列，调用同一通用引擎。
- `src/friend-table-policy.mjs`：翻前尺度提议、牌力、牌面纹理与真实听牌分析，供通用引擎构造候选。
- `src/friend-table.mjs`：发牌、固定物理座位、庄位轮转、本地存储迁移和逐街展示快照。

模拟风格是可修改的程序配置，不是对这些真人牌友的玩法画像；`review-people.mjs` 中待补充的真实特点仍单独维护。

当前策略版本为 5；完整算法、API、增量收益公式与近似边界见 [德州决策引擎](holdem-decision-engine.md)。历史娱乐频率不作为本版强制配额。

## 下注与加注

翻牌、转牌、河牌均允许下注、加注、再加注及过牌后加注。一次加注发生后，之前已经过牌或跟注的未弃牌玩家也必须获得回应机会，直到所有继续玩家匹配最新下注额。

最小加注按上一次下注或加注的增量计算。例如有人下注5BB，随后加至15BB，下一次完整加注至少到25BB。引擎不再使用“这一轮已经下注过，所以禁止再加注”的开关，也不把策略性的谨慎跟注当成德州规则中的加注封顶。[规则参考](https://www.pokerstars.com/poker/games/texas-holdem/)

当前仍采用无全下／边池的深筹码模拟范围，通过可覆盖筹码上限约束动作；未实现完整现金局的买入、补码或跨手输赢余额。

## 独立决策

每人使用独立的决策器与可复现随机序列。随机选择由本手种子、玩家身份、当前街和本人的决策次数决定，不与其他玩家共享条件消耗的随机序列。

决策输入仅包含自己的两张手牌、已翻出的公共牌、公开的筹码和历史行动。对手底牌、未翻出的公共牌及最终赢家不进入决策器。固定种子下，重放相同信息会得到相同选择。

价值下注／加注、真实听牌半诈唬和纯诈唬分别处理。诈唬只在适合的位置、人数、牌面与下注成本下考虑；多人底池会更谨慎。强牌也需要结合公共牌危险程度、对手施压与投入成本判断，不能把“牌型名称较大”直接等同于无条件连续抬价。[诈唬与半诈唬参考](https://www.pokerstars.com/poker/learn/lesson/bluffing/)

日志中的 `decisionProbabilities` 是本次动作选择权重，`bluffProbability` 是当前机会下的纯诈唬选择概率；浮窗的“诈唬基准”来自玩家模拟配置，只在存在合适纯诈唬机会时使用，半诈唬另由听牌进攻参数控制。它们都不是获胜概率。批量报告中的诈唬动作比例另以实际发生的动作数量统计。

## 固定座位与轮转

`seatOrder` 保存物理座位的顺时针人物顺序，`seatIndex` 标识0至6号物理座位。页面按这个索引摆放头像；`position` 仅标记这一手的UTG、LJ、HJ、CO、BTN、SB、BB角色。

首局庄位位于4号座位。每次“再来一局”仅将 `buttonSeat` 顺时针推进一位，小盲、大盲随之移动，人物和物理座位关系不变。位置索引为UTG=0到BB=6时：

`seatIndex = (buttonSeat + positionIndex - 4 + 7) % 7`

例如首局0号座位为UTG，下一局变为BB；原SB玩家下一局为BTN，原BB玩家下一局为SB。七手后每人轮完全部位置。刷新页面只恢复当前这手，不触发轮转。

旧缓存升级时保留牌友、牌面、起始筹码和已有位置，并据此建立固定座次。已弃牌状态只根据当前查看的街显示；回到弃牌前的街，头像恢复正常。
